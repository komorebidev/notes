# MFA authentication for RDP

* Notes for Cisco Duo authentication for RDP
* Offers silent install and updates
* Needs reboot sometimes
* https://duo.com/docs/rdp

## Considerations

* Defeatable by safe mode
* Needs additional setup to authenticate by Microsoft account
* Needs to be installed on each PC
* Needs regular patching
